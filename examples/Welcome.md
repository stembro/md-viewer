# A quieter way to read

Your notes, beautifully at home. **Markdown Viewer** turns plain-text documents into a comfortable reading experience, with just the tools you need.

> Good ideas deserve a little breathing room.

## Make yourself at home

Open any Markdown file with **Ctrl + O**, or drag it into the window. Use the outline on the left to move through longer documents, and switch to a softer dark theme when the day winds down.

There is no workspace to set up and nothing to sync. Just open a file and read.

## The little things, considered

| When you want to… | Try this |
| :--- | :--- |
| Find a phrase | **Ctrl + F**, then Enter |
| Give the page more room | **Ctrl + B** to hide the outline |
| Make the words a little larger | **Ctrl + +** |
| Return to the original size | **Ctrl + 0** |
| Print a document | **Ctrl + P** |
| Go back to the previous file | **Alt + Left** |

### Everything in its place

- [x] Headings, lists, and thoughtfully spaced paragraphs
- [x] Tables, quotations, and fenced code blocks
- [x] Local images and links between Markdown documents
- [x] Automatic refresh when your editor saves a change

### For the details

Inline `code` stays crisp. Longer examples have their own space:

```csharp
var document = "An idea worth keeping.md";
Open(document);
```
